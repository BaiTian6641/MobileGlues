Date: 2026-10-20. Device: HP Googlebook 14, serial `C1L63708PZ`, Snapdragon
X1E80100 / Adreno X1-85, Android 17 / API 37.

## Commands

```sh
# Host: pinned Vulkan GLSL -> glslang -> SPIRV-Cross ESSL 320 -> ESSL validation
sh tools/fsr3_spike/reproduce.sh

# Device: rebuild the probe with a static C++ runtime, then run the operation probe
ANDROID_NDK_HOME=$HOME/Android/Sdk/ndk/28.2.13676358 \
  sh tools/fsr3_spike/probe/build_android.sh
adb -s C1L63708PZ push tools/fsr3_spike/probe/fsr3_gles_probe_arm64 /data/local/tmp/fsr3_gles_probe
adb -s C1L63708PZ shell 'chmod 755 /data/local/tmp/fsr3_gles_probe && \
  /data/local/tmp/fsr3_gles_probe' > device-probe.json

# Device: compile the adapted ESSL files. The shader package is generated by
# tools/fsr3_spike/study/inline_adapt.py and is not committed as a binary blob.
adb -s C1L63708PZ push <generated-shaders> /data/local/tmp/fsr3_shaders/
adb -s C1L63708PZ shell 'cd /data/local/tmp && ./fsr3_gles_probe \
  --compile-shader /data/local/tmp/fsr3_shaders/*_essl320.glsl' \
  > device-shader-compile.json
```

The first probe build used the NDK's shared libc++ and failed to start with
`library "libc++_shared.so" not found`. The build script now passes
`-static-libstdc++`; the results below are from the corrected static binary.

## Results

Operation probe: **14/22 PASS**. Expected failures:

- `r8`, `r16f`, `rg16f` image load/store: invalid ESSL layout qualifier. The port
  substitutes RGBA8/RGBA16F.
- formatless writeonly image: requires an explicit format qualifier. The port
  emits RGBA8/RGBA16F variants.
- subgroup quad swap: `GL_KHR_shader_subgroup_quad` absent. SPD uses the SDK's
  `FFX_SPD_NO_WAVE_OPERATIONS` shared-memory fallback.

Required substituted operations that PASS:

- compute limits: 1024 invocations, 192 compute image uniforms, 32 KiB shared
  memory, 256x1 workgroup;
- RGBA8, RGBA16F, R32F and RGBA32F image store/load round trips;
- R32UI image atomics, 256-thread shared reduction, SSBO atomics;
- readonly/writeonly alias image units on one texture;
- combined sampler `texelFetch`/`textureLod`/`textureSize`, std140 UBO.

Shader compile: **12/12 PASS** on ANGLE/Adreno. This is the 10 base passes plus
the RGBA8 and RGBA16F output variants of Accumulate/RCAS.

## What this does not prove

Compilation and isolated resource operations are not dispatch correctness. No
FSR3 pass has run on the target, no history/barrier chain has executed, and no
image quality or frame-time result exists. The next gate is a deterministic
single-pass dispatch, then the full 8-pass chain against the reference.
